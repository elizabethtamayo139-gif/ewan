HTML Tables

Tables are used to organize information into rows and columns.

Basic Table Code

<table>

    <tr>
        <th>Name</th>
        <th>Age</th>
        <th>Grade</th>
    </tr>

    <tr>
        <td>John</td>
        <td>15</td>
        <td>10</td>
    </tr>

</table>

Example Table

Name Age Grade
John 15 10
Maria 16 10
Alex 15 10

Remember:

  • <table> = creates a table
  • <tr> = table row
  • <th> = table heading
  • <td> = table data

HTML Navigation

Navigation allows visitors to move from one section or webpage to another.

Navigation Example

<nav>

    <a href="#home">Home</a>

    <a href="#about">About</a>

    <a href="#contact">Contact</a>

</nav>

What does href mean?

href tells the browser where the link should go.

For example: 

<a href="#home">Home</a>

The #home connects to an element with id="home". 

<section id="home">

    <h2>Welcome Home</h2>

</section>

HTML Elements and Their Purposes

HTML Element Purpose
<html> Defines the whole HTML document.
<head> Contains information about the webpage.
<title> Sets the title shown on the browser tab.
<body> Contains the visible content of the webpage.
<h1> Creates the main heading.
<p> Creates a paragraph.
<a> Creates a hyperlink.
<img> Displays an image.
<br> Creates a line break.
<div> Creates a general container for content.
<span> Groups inline content.
<ul> Creates an unordered/bullet list.
<ol> Creates an ordered/numbered list.
<li> Defines a list item.
<table> Creates a table.
<tr> Creates a table row.
<th> Creates a table heading.
<td> Creates a table data cell.
<form> Creates a form for user input.
<input> Creates an input field.
<label> Provides a label for an input.
<button> Creates a clickable button.
<select> Creates a dropdown menu.
<option> Creates an option inside a dropdown.
<textarea> Creates a multi-line text input.
<header> Defines the header of a webpage or section.
<nav> Contains navigation links.
<main> Contains the main content of the webpage.
<section> Groups related content.
<footer> Defines the footer of a webpage.
<audio> Adds audio to a webpage.
<video> Adds video to a webpage.
<iframe> Embeds another webpage or content.
<script> Adds JavaScript to a webpage.
